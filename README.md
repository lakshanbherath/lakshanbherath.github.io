# Everyday Apps — Premium GitHub Pages Site

## Upload
Create `YOUR_USERNAME.github.io` on GitHub, then copy the contents of this folder into the repository root.

## Pages included
- `/` — polished portfolio homepage
- `/apps/<app>/` — individual marketing page for each app
- `/privacy/<app>/` — app-specific privacy URL
- `/support/<app>/` — app-specific support URL

## IMPORTANT before publishing
1. Replace `Everyday Apps` with your actual developer/studio name if desired.
2. Replace `support@example.com` and `privacy@example.com`.
3. Replace every App Store button `href="#"` with its real App Store URL.
4. Customize each privacy policy so it exactly matches the app's real data practices.
5. Review medical/financial disclaimers for your actual app functionality.
